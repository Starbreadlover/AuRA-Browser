# Branding And Legal Notes

Mozilla Firefox source code can be forked under its open-source licenses, but Mozilla and Firefox names, logos, product trade dress, and related marks are protected. AuRA Browser must not ship as a rebranded product that still looks or behaves as official Firefox.

## Required Branding Work

Replace visible final-product branding in:

- Application display name.
- Executable and package names.
- Installer product name and metadata.
- macOS `.app`, bundle identifier, helper app names, `.dmg`, signing identity, and notarization metadata.
- Profile folder name.
- Icons, logos, splash/about artwork, and installer artwork.
- About pages and settings text.
- Update channel names and release notes URLs.
- Default support, feedback, and website links.

## Do Not Ship

- Firefox logos.
- Mozilla logos.
- Official Firefox product names in UI, installer, or release branding.
- Any claim that AuRA Browser is produced, endorsed, certified, or supported by Mozilla.

## Safer Wording

Acceptable project documentation can say AuRA Browser is based on open-source Mozilla Firefox / Gecko code. The product UI should simply say AuRA Browser and Gecko-powered where needed.

## Legal Reminder

This is not legal advice. Before public distribution, review the Mozilla Public License obligations, third-party notices, trademark policy, and installer/update branding with counsel or a qualified release engineer.

Reference: https://www.mozilla.org/foundation/trademarks/policy/
